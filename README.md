A game about a detective, an AI, and what it means to be human.

### 🧠 About
**PDL (Please Don’t Lie)** is a visual novel built in Ren’Py, following Detective Daniel Reeds as he investigates the mysterious death of Parker Gammbel — the creator of AWaRE, an AI that might just be too self-aware.

## Installation
- Download release from releases page
- Unzip the .zip archive
- Execute main executable in .zip archive previously downloaded.
